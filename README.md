## Polymarket CLOB Python Backend (Demo)

Минимальный backend‑проект на Python для работы с Polymarket API:
- **Gamma API** — для получения списка рынков (market discovery)
- **CLOB API** — для торговли (получение orderbook, размещение ордеров)

Использует официальный клиент `py-clob-client` для CLOB API и прямые HTTP-запросы к Gamma API.

### Кэширование рынков

Проект автоматически кэширует загруженные рынки в файл `markets_cache.json` в корне проекта.

**Как это работает:**
1. При первом запросе рынки загружаются с API и сохраняются в кэш
2. При последующих запросах с тем же фильтром поиска сначала проверяется кэш
3. Если в кэше найдено точное совпадение по фильтру — используются данные из кэша (быстро, без запросов к API)
4. Если фильтр не совпадает или кэш отсутствует — загружаются новые данные с API и кэш обновляется

**Преимущества:**
- Быстрый доступ к данным без запросов к API
- Экономия времени и ресурсов при повторных запросах
- Автоматическое обновление кэша при изменении фильтра

**Примечание:** Файл `markets_cache.json` автоматически добавляется в `.gitignore` и не попадает в репозиторий.

### Автоматическое обновление рынков

Проект автоматически обновляет рынки каждые 15 минут.

**Как это работает:**
1. При запуске приложения проверяется время последнего обновления (хранится в `markets_last_update.json`)
2. Если прошло больше 15 минут с последнего обновления — рынки обновляются автоматически
3. Фоновый поток проверяет время каждую минуту и обновляет рынки при необходимости
4. Время последнего обновления сохраняется в файл `markets_last_update.json`

**Преимущества:**
- Актуальные данные без ручного обновления
- Автоматическая проверка каждую минуту
- Обновление только при необходимости (не чаще раза в 15 минут)

**Примечание:** Файл `markets_last_update.json` автоматически добавляется в `.gitignore` и не попадает в репозиторий.

### Настройка параметров приложения

Файл `app/app_config.py` содержит настройки приложения, которые можно изменять без изменения кода:

- `market_search_filter` — строка для поиска рынков по названию (клиентская фильтрация)
- `gamma_api_tag_id` — ID тега для фильтрации рынков по категории (None = без фильтрации)
  - Получить список доступных тегов: `curl "https://gamma-api.polymarket.com/tags?limit=100"`
  - Примеры: `2` (Crypto), `21` (Politics), `100639` (Sports games)
- `max_markets_limit` — максимальное количество рынков для получения (0 = без ограничений)
- `gamma_api_active_only` — получать только активные рынки
- `gamma_api_closed` — включать закрытые рынки

```python
# Параметр фильтра для поиска рынков (используется по умолчанию)
market_search_filter: str = "Bitcoin Up or Down"

# Использовать Gamma API по умолчанию
use_gamma_api: bool = True

# Максимальное количество рынков (0 = без ограничений)
max_markets_limit: int = 10000

# Параметры для Gamma API
gamma_api_active_only: bool = True
gamma_api_closed: bool = False
# tag_id для фильтрации по категории (None = без фильтрации)
# Получить список: curl "https://gamma-api.polymarket.com/tags?limit=100"
gamma_api_tag_id: int | None = None
```

**Пример изменения фильтра поиска:**

Откройте `app/app_config.py` и измените:

**Один фильтр (строка):**
```python
market_search_filter: str = "Bitcoin Up or Down - January 12, 10:45AM-11:00AM ET"
```

**Несколько фильтров (список):**
```python
market_search_filter: list[str] = [
    "Bitcoin Up or Down - January 12, 10:45AM-11:00AM ET",
    "Bitcoin Up or Down - January 12, 11:00AM-11:15AM ET",
    "Bitcoin Up or Down - January 12, 11:15AM-11:30AM ET"
]
```

**Примечание:** Фильтрация работает по **полному совпадению** названия рынка с фильтром (без учета регистра). Если название рынка точно совпадает с фильтром, он будет включен в результаты.

**Пример фильтрации по тегу (категории):**

Откройте `app/app_config.py` и установите тег по названию (рекомендуется):
```python
gamma_api_tag: str | None = "Crypto"  # Только рынки категории Crypto
```

Или по ID напрямую:
```python
gamma_api_tag_id: int | None = 2  # Только рынки категории Crypto (по ID)
```

**Примечание:** Если задан `gamma_api_tag`, параметр `gamma_api_tag_id` игнорируется.

**Просмотр доступных тегов:**

Используйте встроенную утилиту для просмотра всех доступных тегов:

```bash
# Показать первые 100 тегов
python -m app.list_tags

# Показать больше тегов
python -m app.list_tags --limit 200

# Поиск тегов по названию
python -m app.list_tags --search crypto
python -m app.list_tags --search politics

# Вывести в формате JSON
python -m app.list_tags --json
```

Или через curl напрямую:

```bash
curl "https://gamma-api.polymarket.com/tags?limit=100"
```

**Примеры популярных тегов:**
- `2` — Crypto
- `21` — Politics  
- `100639` — Sports games
- `None` — без фильтрации по тегу

**Важно:** `tag_id` работает для endpoint `/events`, а не для `/markets` напрямую. 
При использовании `tag_id` код автоматически переключается на `/events` endpoint.

### Запуск

#### Тестовый прогон (рекомендуется для начала)

**Запуск тестового прогона для проверки подключения:**

```bash
python -m app.main test
```

Тестовый прогон выполняет:

- ✓ Проверку конфигурации (API URL, адрес кошелька)
- ✓ Инициализацию клиента
- ✓ Проверку подключения к API
- ✓ Получение информации об аккаунте и балансе
- ✓ Тест получения рынков и orderbook
- ✓ Тест dry-run режима для ордеров (симуляция без реальной отправки)

Это безопасный способ проверить, что всё настроено правильно, без создания реальных ордеров.

#### Интерактивный режим

**Запуск интерактивного CLI:**

```bash
python -m app.main
```

Скрипт:

- **читает конфиг** из `.env`;
- **выводит список рынков**, отфильтрованных по строке (по умолчанию `"Bitcoin Up or Down"`);
- даёт выбрать `market_id` и **показывает orderbook**;
- предлагает **явно подтвердить** покупку или продажу (по умолчанию ничего не покупает и не продаёт);
- поддерживает **dry-run режим** для безопасной симуляции ордеров.

### Что можно протестировать

#### В тестовом прогоне (`python -m app.main test`)

- ✓ Проверка подключения к API
- ✓ Получение информации об аккаунте
- ✓ Получение баланса (если поддерживается API)
- ✓ Получение списка рынков
- ✓ Получение orderbook для тестового рынка
- ✓ Симуляция buy/sell ордеров в dry-run режиме

#### В интерактивном режиме (`python -m app.main`)

- **Вывод списка рынков**
  - После запуска скрипта вы увидите список рынков с их `id` и названием.

- **Просмотр orderbook**
  - Введите индекс рынка из списка — скрипт выведет его orderbook (лучшую цену/объёмы по bid/ask).

- **Ручной вызов buy/sell**
  - После просмотра orderbook скрипт спросит, хотите ли вы сделать `buy` или `sell`.
  - Вы можете выбрать **dry-run режим** для безопасной симуляции без реальной отправки ордера.
  - Вы укажете:
    - исход (`outcome` — обычно индекс 0 или 1 для бинарных рынков);
    - сумму в USDC;
    - лимитную цену.
  - Реальные ордера **будут выполнены только после явного подтверждения в консоли**.

### Безопасность

- **Dry-run режим**: Используйте `dry-run` для тестирования логики без реальных сделок.
- **Подтверждение**: Реальные ордера требуют явного подтверждения в консоли.
- **Приватный ключ**: Никогда не коммитьте `.env` файл с приватным ключом в репозиторий.

**Внимание**: Реальные ордера требуют валидного приватного ключа и достаточного баланса; используйте проект на свой риск и только с теми средствами, которыми готовы рискнуть.
